## 关键结论（踩坑记录）
- GitHub 无 macos-27 runner 标签；macOS 27.0.1 镜像的标签是 **xcode-27**（arm64 公共预览，预装 Xcode 27.0.0 GM）
- Apple 版本线无 Xcode 27.0.1 / iOS 27.0.1（27.0.0 → 27.1.0 → 27.2 beta）；CI 锁定 27.0.0，模拟器优先 27.0.1 回退 27.0
- workflow `if:` 表达式必须用**单引号**，双引号导致整个 workflow 校验失败（0s 失败、无 job）
- xcodebuild -version 对 27.0.0 输出 "Xcode 27.0"（无第三段），校验正则要兼容
- Swift 计算属性块内不能有以 `get` 开头的方法调用（get 是访问器关键字）→ KeychainStore 方法改名 string(forKey:)
- SwiftUI `.alert(item:)` 的 content 闭包返回 `Alert`（带 dismissButton），不是按钮 ViewBuilder + message: 组合
- `ASAuthorizationAppleIDProvider.getCredentialState` 回调签名 (state, error)
- 本地验证 Swift 语法：`swiftc -parse`（Windows Swift 6.4，路径 C:/Users/liu20/AppData/Local/Programs/Swift/Toolchains/6.4.0+Asserts/usr/bin/swiftc.exe）；**必须先去掉大写 HTTPS_PROXY/HTTP_PROXY/ALL_PROXY 环境变量**（大小写重复键导致 Swift runtime 崩溃）
- 用户全局 git 配置曾有 gitclone.com 代理重写（已按用户要求删除）；沙箱代理 127.0.0.1:51964 拦截 git，推送用 `git -c http.proxy=http://127.0.0.1:18081 -c https.proxy=http://127.0.0.1:18081 push`
- EdgeOne Functions 限制：body ≤1MB（→ 600KB 分片上传）、CPU 200ms（→ waitUntil 异步 + 2s 轮询）、KV 最终一致性 60s（→ 分片读取重试）；KV 绑定变量名固定 PAGEMAKE
