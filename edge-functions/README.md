# Page-make 后端 · EdgeOne Pages Functions

静态网页托管服务的边缘函数（JavaScript，ES2023+）。部署到 EdgeOne Pages / Makers 平台，
平台自动识别仓库根目录下的 `edge-functions/` 目录生成路由。

## 路由表

| 文件 | 路由 | 说明 |
| --- | --- | --- |
| `index.js` | `/` | 服务信息 |
| `api/auth.js` | `/api/auth` | POST：Sign in with Apple 换会话凭证（7 天） |
| `api/config.js` | `/api/config` | GET：公开限制信息 |
| `api/upload/init.js` | `/api/upload/init` | POST：初始化分片上传 |
| `api/upload/chunk.js` | `/api/upload/chunk` | POST：上传单个分片（≤1MB body 限制 → 600KB/片） |
| `api/upload/finish.js` | `/api/upload/finish` | POST：完成上传，后台处理（processing → ready/failed） |
| `api/projects.js` | `/api/projects` | GET：我的项目列表 |
| `api/projects/[id].js` | `/api/projects/:id` | GET 详情 / DELETE 删除 |
| `api/projects/[id]/status.js` | `/api/projects/:id/status` | GET：状态轮询 |
| `api/projects/[id]/refresh.js` | `/api/projects/:id/refresh` | POST：刷新链接（EdgeOne 3 小时限制） |
| `api/projects/[id]/files.js` | `/api/projects/:id/files` | POST 添加 / DELETE 删除文件 |
| `api/feedback.js` | `/api/feedback` | POST：反馈 / 举报 |
| `p/[projectId].js` | `/p/:projectId` | 公开访问（无需登录）：入口文件 |
| `p/[projectId]/[[default]].js` | `/p/:projectId/*` | 公开访问：静态资源 |

## 数据存储（EdgeOne KV）

一个命名空间，绑定变量名固定为 `PAGEMAKE`，按 key 前缀隔离：

| 前缀 | 表 | 内容 |
| --- | --- | --- |
| `user_` | users | userId、email、status、banLevel、banUntil、banReason、banCount |
| `project_` | projects | id、userId、provider、entryPath、fileCount、size、status、errorCode、sourceType、autoGenerated、diagnostics、runtimeErrors、createdAt、expiresAt、url、deploymentUrl、files |
| `session_` | — | 会话凭证（token 哈希 → userId + 7 天有效期） |
| `site_` | — | 项目文件内容（`site_<id>_<路径hex>`，供 /p/ 路由与刷新使用） |
| `meta_` | — | 项目文件清单元信息 |
| `tmp_` | — | 上传临时分片 |
| `uproject_` | — | 用户项目索引 |
| `log_` | logs | step、result、errorCode、duration |
| `feedback_` | feedback / bans | 反馈、举报记录 |
| `upload_` | — | 分片上传任务 |

KV key 仅允许数字、字母、下划线 → 所有 key 部件经 UTF-8 十六进制编码（`lib/base64.js`，可逆）。

## 两条线路

- **EdgeOne（主线路）**：文件写入 KV，由本项目 `/p/` 路由直接服务。
  默认域名有 3 小时预览限制 → `expiresAt` 设为 3 小时，用户在 App 内手动刷新
  （或后续版本做后台自动续期）。使用自定义域名可解除限制。
- **Cloudflare（备选线路）**：Direct Upload 部署到 Cloudflare Pages，`/p/` 302 跳转。
  需在控制台配置 `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID` / `CLOUDFLARE_PAGES_PROJECT`。
  注意：*.pages.dev 在国内访问不稳定（已知问题，App 内向用户说明）。

## 环境变量（控制台 → 环境变量，绝不进仓库）

| 变量 | 说明 |
| --- | --- |
| `APPLE_CLIENT_ID` | iOS App Bundle ID（校验 Apple token 的 aud） |
| `CLOUDFLARE_API_TOKEN` | Cloudflare 令牌（备选线路） |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare 账户 ID |
| `CLOUDFLARE_PAGES_PROJECT` | Cloudflare Pages 项目名 |

KV 绑定变量名固定为 `PAGEMAKE`。

## 平台限制（已适配）

- 请求 body ≤ 1MB → 分片上传（600KB/片，iOS 端同样分片）
- 代码包 ≤ 5MB / CPU 200ms → 上传处理走 `waitUntil` 异步，状态机轮询
- KV 最终一致性（边缘缓存 ≤60s）→ 分片读取带重试；文件清单在 `meta_` 中冗余
- KV 值 ≤ 25MB、账户容量 1GB → 单个项目 ≤ 5MB（客户端校验）
