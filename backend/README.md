# Page-make 后端（API 处理器）

静态网页托管服务的 API 层（JavaScript ESM，ES2023+，仅 Node 标准库）。

**运行方式**：由 `docker/server.mjs`（容器适配层）以普通 Node HTTP 服务运行，
部署在 ModelScope 创空间（Docker 类型）。处理器原本为 EdgeOne Pages Functions 编写，
`onRequest(context)` 签名与 Web 标准 API（fetch / crypto.subtle / DecompressionStream）
在容器中原样可用，业务逻辑与边缘版完全一致。

## 数据存储

容器版为**磁盘 KV**（`docker/server.mjs` 的 `DiskKV`，目录 = `DATA_DIR`），
API 与 EdgeOne KV 一致（get/put/delete/list），key 前缀隔离：

| 前缀 | 表 | 内容 |
| --- | --- | --- |
| `user_` | users | userId、email、status、banLevel、banUntil、banReason、banCount |
| `project_` | projects | id、userId、provider、entryPath、fileCount、size、status、errorCode、sourceType、autoGenerated、diagnostics、runtimeErrors、createdAt、expiresAt、url、deploymentUrl、files |
| `session_` | — | 会话凭证（token → userId + 7 天有效期） |
| `site_` | — | 项目文件内容（`site_<id>_<路径hex>`，供 /p/ 路由与刷新使用） |
| `meta_` | — | 项目文件清单元信息 |
| `tmp_` | — | 上传临时分片 |
| `uproject_` | — | 用户项目索引 |
| `log_` | logs | step、result、errorCode、duration |
| `feedback_` | feedback / bans | 反馈、举报记录 |

KV key 仅允许数字、字母、下划线 → 所有 key 部件经 UTF-8 十六进制编码（`lib/base64.js`，可逆）。
写盘走「临时文件 + 重命名」保证原子性；启动时扫描目录建内存索引。

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `PORT` | 监听端口（ModelScope 约定 7860） |
| `DATA_DIR` | 数据目录（创空间持久卷 `/mnt/workspace/pagemake-data`） |
| `APPLE_CLIENT_ID` | iOS Bundle ID（校验 Apple 登录 token 的 aud） |
| `DEV_NO_AUTH` | 仅本地调试：设为 1 跳过登录鉴权（**生产禁止**） |

## 部署形态说明

- **容器（当前唯一形态）**：文件落盘，`/p/` 路由本地提供，链接长期有效
- **线路选择**：`provider` 字段保留 iOS 端契约（`edgeone` / `cloudflare`），容器模式下两者均本地服务；
  配置了 Cloudflare 凭证时 `cloudflare` 走 Direct Upload（`lib/deploy/cloudflare.js`），否则自动降级本地服务
- **过期**：登录用户的链接长期有效（`expiresAt` 为 null，直到用户删除）；**游客**创建的链接 10 分钟后自动失效
  （所有线路统一按 `expiresAt` 判定：`/p/` 路由 410 过期页、项目状态报 `expired`；游客「刷新」可重新计时 10 分钟）

## 平台限制适配（历史）

- 请求 body ≤ 1MB → 分片上传（600KB/片，iOS 端同协议）
- 上传处理走 `waitUntil` 异步 + 状态轮询（容器版 fire-and-forget，同样机制）
- KV 最终一致性 → 分片读取带重试
